I was cleaning up my HD's when I found these files I've downloaded years ago (2004) from Dime. I checked if these files were still available on Dime; this is not the case.

I did not make any modification to the files regarding sound quality, however I noticed I had edited the ID-tag and changed the name for the folder and the files themselves. 

The original name for the torrent was Johnny Cash American Outtakes
I changed this to cashjohnny199305xx

Some artwork was provided by tmop. This artwork is included as well, with special note that some work still needs to be done to fit the artwork with the files included
