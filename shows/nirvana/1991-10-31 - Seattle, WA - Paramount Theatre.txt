I downloaded this one from www.nirvlove.com.  It appears to be straight from the
Andy Wallace mix.  Not sure of the exact lineage since it was not given with the files, 
though it is definetaly a lossless source.  As far as I know this is the best source of this show.
The shows speed was a bit fast, which is known of the Andy Wallace mix, so I corrected it in much
the same way the of Mike Wilkinson remaster, but I did not use officially released sources.
The overall time was about 1min fast.  I simply matched the first beat of a track to the last beat
using the few tracks from this show that were released on a few singles.  Pretty simple method really.
I've also re-split tracks a bit more accurately.  I seperated the very long pause after Blew
into a seperate track as well, though I wasn't sure if I should.
Since it was over 3min of nothing it seemed like it would be easier to skip or exclude from
a cd if someone wanted it that way.  I did no EQing or anything else.  Here it is, the
Andy Wallace mix, speed corrected and all that.  Enjoy!
