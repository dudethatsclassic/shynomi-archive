# Hendrix material only.

# Commercially available material banned - no DVD rips or EH
  (Experience Hendrix - his record label) discs.

# Lossless formats only - no mp3. Each show or CD should be
  filed in a folder of it's own with each of the individual
  files (commonly in .shn or .ape format - see links below).
  Also include a text file giving information on the contents:
  tracklist, song lengths, source etc. Finally, create an md5
  (or equivalent, e.g. sfv) file which will check the integrity
  of each file. When someone downloads the music files & checks
  them with this md5 file they can be sure that their copies of
  the files do not contain errors.

# I'm tempted to insist that people share at least 2GB. However,
  at the moment the minimum share is just 500MB so that everyone
  can get started. (There are even ways around this limit, if
  necessary)

# Minimum slots 2

# Max number of hub connected to 10, but when connected to more
  than one hub, you need at least 1 slot per hub

# No clones - i.e. don't connect as 2 different users from the same
  machine/ip. It's easy to check the IP address of each user. If you
  use other hubs and share files there which I do not allow (warez,
  mp3's...), use one program for those hubs (DC++) and a different
  one for my hub (I'd recommend Phantom DC++). You can't have 2
  instances of DC++ running simultaneously so a 2nd prog is required.
