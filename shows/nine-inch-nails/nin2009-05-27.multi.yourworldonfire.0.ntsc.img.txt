Notes:
I went down a rabbit-hole the other day and started reading more into this project. This was a fan made project of the KC show of this tour. Multiple camera angles and audio sources mixed into one release. Limited to a standard def release because of some of the video sources. Still, a good little project. They were going to revive this and try to make a release from the St. Paul 2013 show, but I don’t think that ever got off the ground. The website of this release is now defunct and the only thing I had was the ISO file to make the DVD.

If anyone from this project wants to email me more about some of the process, or wants to add information about it. Please get in contact through the archive’s email!
