Big thanks to ellaguru for transferring this LP Mode DAT for me. It’s a DAT clone from the DAT master, but that is all I know. This is different than the D. Merz source that is from this show as well. The tape is pretty good and includes the 5 minutes or so of the encore break that the DM source does not. The other difference is that the DM source has more of the pre-show before ‘Pinion’ than this tape. 

This DAT clone was made in LP mode (16/32) and in order to burn this properly to a CD, the audio file was converted to 16/44 so that everyone can burn these to a CD if desired.
