Info:
This is a direct capture of the iTunes stream of the show. I simply used Wireshark to find the address of the of the .ts files and then downloaded the files directly using Safari because it had the proper cookie authorizing the downloads. Then I used TSSplitter to join the 485 .ts segments into a single file. For some reason however, there is a problem with the audio when playing the file back with VLC on Windows. Windows Media Player is able to play it without any issues though.
