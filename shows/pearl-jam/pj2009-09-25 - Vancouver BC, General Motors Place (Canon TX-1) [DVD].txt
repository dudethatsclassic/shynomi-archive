How I print the DVD cover and the dvd labels:
These steps are based on using a Canon inkjet printer and Canon PhotoRecord software.  I've made multiple dvds and this works well.

I've made both the DVD sleeve and DVD label images 8.5"X11" in size so if you print with the borderless setting on, everything should be the correct size.  I print the dvd sleeve on Canon Semi-glossy Photo Paper.  The label placement is based on Avery Inkjet CD labels template 08692.
