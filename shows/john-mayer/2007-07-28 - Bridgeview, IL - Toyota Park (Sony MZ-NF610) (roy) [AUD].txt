Crossroads Music Festival

July 28, 2007

Toyota Park, Bridgeview, IL

Roy's audience source recorded mid-field next to the soundboard tent.

Recorded on Sony MZ-NF610 MiniDisc using a set of Premium Binaural Mics clipped to Roy's eyeglasses.

Transferred via Sony MDS-JE510 -> fibre optic cable -> ADS Tech box -> USB -> computer

Recorded using SoundForge.  Misc. editing with Cool Edit Pro.  Chopped up into tracks using CD Wave Editor.

Encoded into FLAC Level 7 using Trader's Little Helper.

Setlist

01. Introduction
02. Waiting On The World To Change
03. Belief
04. Vultures
05. I Don't Need No Doctor
06. Gravity
