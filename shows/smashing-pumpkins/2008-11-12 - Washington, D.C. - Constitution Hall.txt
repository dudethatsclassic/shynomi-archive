The Smashing Pumpkins 
2008.11.12 
D.A.R Constituion Hall

Video recording shot using Canon FS300 in XP quality mode to SD memory card.  Original files were in .MOD format. To change them to MPG, all I had to do was rename the file .MOD extension as .MPG, which is losless.

Shot from Front Row, just about dead center.
During first few songs, security was not allowing taping, so Rocktopus, Ava Adore, Owata, and Cupide are Missing.  So the recording starts with 1979.
Includes most of the concert, minus about 10 minutes towards the end when my battery was running low and I wanted to save the last bit for when he said farewell to the crowd.
Audio isn't great on heavy distortion songs, so if anyone knows a way to clean it up or sync it with soundboard, please let me know. Otherwise good recording.
